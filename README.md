# Examplay — site web

Next.js (App Router), TypeScript, Tailwind v4, Supabase.

## Démarrer

```bash
npm install
npm run dev
```

Variables d'environnement : voir `.env.example` (à renseigner aussi dans Vercel).

## Base de données

Exécuter `supabase/migrations/20261004_waitlist.sql` dans le SQL Editor de Supabase.
